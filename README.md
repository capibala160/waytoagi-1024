---

## 怎么在手机上打开

按顺序试，能通就行：

1. **阿里云服务器（最稳）**
   把这个 HTML 传到你那台已备案的服务器，用 `https://你的域名/任意路径/compass-test.html` 打开。

2. **临时隧道（最快）**
   电脑上在本目录起静态服务，再开隧道：
   ```bash
   python -m http.server 8080
   npx cloudflared tunnel --url http://localhost:8080
   ```
   把隧道打印出来的 `https://xxxx.trycloudflare.com/compass-test.html` 发到手机。

3. **本地 http**
   只能看界面，手机拿不到传感器（Chrome 直接不给数据）。只用于改样式。

## 通过标准

| 现象 | 判断 |
|---|---|
| 点「开始」后数字随转动变化，静止时 ±5° 内 | ✅ 能做 |
| 数字卡在 `--` / 一直不动 | ❌ 换手机 / 换浏览器 |
| 抖动 ±20° 以上 | ⚠️ 画 8 字校准后再看 |
| 提示「权限被拒绝」 | iPhone：设置 → Safari → 动作与方向 → 允许 |
| 两台手机都拿不到 | ❌ 这个方向今天放弃 |

**用你要演示的那台手机测。** 安卓（vivo）通常比鸿蒙 / iPhone 稳。

点「复制诊断」，把结果发我，我判断能不能往下做。
