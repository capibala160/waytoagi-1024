# 犟针 · 只指方向，不指路

WaytoAGI 1024 超能 Coding 周末 · 游戏赛道

说一个地方，屏幕只给一个指南针。没有地图、没有路线、没有距离——自己找路，到了才算数。

> **产品方向：目的地优先。** 首页是「今天去哪？」，确认目的地后选「手机模拟 / 去真实城市」，罗盘只指它。
> 会场寻宝（5 站 / 3 站）保留为备用模式，和自由行共用同一台引擎。
> 读 [docs/PRODUCT-TRUTH.md](docs/PRODUCT-TRUTH.md)。

**在线试玩：** https://capibala160.github.io/waytoagi-1024/
电脑选「手机模拟」，手机有罗盘选「去真实城市」；会场寻宝在首页底部。

## 走法

| 走法 | 场景 | 谁用 |
|---|---|---|
| **手机模拟** | 同一个目的地，12×12 雾城，3–6 分钟 | 评委 / 第一次玩 |
| **去真实城市** | 真实 GPS + 罗盘，30–90 分钟 | 主产品 / 户外演示 |
| **会场寻宝 · 出门玩** | 5 站，约 5 分钟 | 备用模式 |
| **会场寻宝 · 不出门** | 3 站，约 90 秒 | 备用模式，评委兜底 |

## 主流程

1. 首页「今天去哪？」：输入 / 3 张目的地卡 / 换一批 / 随便走走 / 最近去过
2. 确认目的地
3. 怎么走：在这台手机上模拟（雾城）/ 去真实城市
4. 雾城：罗盘 + 四向移动 + 问路 NPC；抵达后出用时 / 步数 / 问路 / 迷路指数 / 星级
5. 旅伴铸造：首页「旅伴」→ 一句话生成 3 个阿针变体 → 选一个，台词和名字跟着变
6. 抵达后「写日记」：时间线 + 3 个照片位 + 一句话 → 生成 9:16 抵达证明 + 挑战链接

目的地数据在 `destinations.js`，填 `name / blurb / lat / lon`。现在的经纬度是成都锦江区的占位点，**换成会场附近的真实地点**。

## 计分

- 目标时间：出门 300 秒、不出门 90 秒、自由行/模拟 600 秒
- 每条提示折算 6 秒
- 得分 = 1000 − 250 ×（用时 + 提示×6）÷ 目标时间，保底 100
- 正常发挥约 750（老向导），快就 850+（活地图）

必须 HTTPS——手机浏览器只在安全上下文里给方向数据。

```bash
cd "/c/Users/Lenovo/Desktop/会场微定向"
```

## 唯一要改的文件：`levels.js`

两套关卡都在这里：`LEVEL_SETS.outdoor`（5 站）和 `LEVEL_SETS.indoor`（3 站）。踩完点，把占位内容换成真的。

```js
{
  id: 1,
  name: '第一站',
  type: 'tutorial',          // tutorial / observe / combine / optional / final
  typeLabel: '教学',          // 线索卡上的小标签
  place: '门口右侧的绿植',     // 内部备注，玩家看不到
  code: '4821',              // 纸上写的四位码
  bearing: 30,               // 目标绝对方位：0=北 90=东 180=南 270=西
  steps: 12,                 // 建议步数，只用于提示文案
  clue: '往北偏东 30°，走十二步……',   // 出发线索：方向 + 步数 + 环境
  arriveClue: '到了墙边再看：……',      // 稳定对准后才揭示
  piece: { mark: '○', label: '0 条边' }, // 这一站的碎片
  confirm: '方向确认，去找那面墙。',     // 稳定对准后显示
  story: '第一段记忆：……',    // 答对后盖章并解锁
  stamp: '门',               // 印章上的一个字
  freeHint: true,            // 教学站提示不耗灯
  bonus: { code: '2077', label: '加试题：……' },  // 可选
  hints: ['第一条', '第二条', '第三条']
}
```

## 游戏化

- **故事**：每站 `story` 一段，答对后盖章并解锁；结算页拼成完整故事。
- **谜题类型** `type`：教学 / 观察 / 组合 / 挑战 / 揭晓，只影响标签和提示规则。
- **提示灯**：每局 3 盏；教学站免费；解谜提示消耗一盏。
- **成就**：记忆拼图 / 独立寻路者（没用解谜提示）/ 细节观察家（答对 `bonus`）/ 同行向导（问了 3 个人）/ 活地图（≥850 分）。
- **加试题**：某站配置 `bonus`，在输码页点「加试一题」。
- **对准光环**：稳定对准 0.9 秒，罗盘外圈亮绿并显示 `confirm`。

> 方位是「上一站 → 下一站」，不要随机打乱站点顺序；要复玩，随机谜题/故事片段，或另配多套路线。

**方位怎么写**：站在上一站的位置，手机平放，转到目标方向，记下读数。填进去。

**线索怎么写**：

- 一定要有方位 + 步数，否则指南针没用
- 描述要「能认出来但不直白」：别写「饮水机」，写「听见水声就到了」
- 每条线索对应一张实体纸，纸上写 4 位码

## 踩点流程（30 分钟）

1. 走一遍会场，选 5 个点：能站人、不挡路、不扰民
2. 站在 A 点，手机转到 B 点方向，记方位角
3. 数一下步数（正常步幅）
4. 每个点贴一张纸，写 4 位码
5. 把 `levels.js` 填完，自己走一遍

## 指南针体检（新手机先跑这个）

`compass-test.html` 会显示：安全上下文、数据来源、静止稳定度、采样率、原始 α/β/γ。

**通过标准**：HTTPS ✅、数据来源是「alpha（绝对）」、静止稳定度 ≤ ±5°。

**注意**：

- 微信内置浏览器会把采样率压到 1 Hz，**一定用 Chrome / 系统浏览器**
- 演示用自己那台手机，别让评委用他们的机型
- 磁吸支架、音箱、金属桌会让罗盘偏，站远一点

## 已知边界（诚实口径）

- 没有 GPS，所以没有真实轨迹；旅程卡上的五站是走完的站点，不是路线图
- 防作弊靠人：玩家可以偷偷用导航，游戏不做裁判
- 采样率低（1 Hz）时，走路读数会滞后；最好站定再读
- 会场 Wi-Fi 可能拦隧道，备手机热点
- 自由行依赖 GPS，室内基本不可用；评委用「不出门」
- 自由行的经纬度目前是成都锦江区占位点，赛前必须换成会场附近真实地点
