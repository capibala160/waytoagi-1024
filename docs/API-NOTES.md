# 图像生成 API · 接入说明

> 用途：生成阿针立绘、地标卡、NPC 头像、海报底纹。
> 原则：**密钥不进前端、不进 docs、不进 git。**

---

## 1. 已收到的信息

- 服务地址：`https://api.2ndcv.com`
- 密钥：已由 Mike 提供，**本文不记录密钥内容**。

只有服务地址还不够。接入前需要确认：

1. 具体的生成接口路径（例如 `/v1/images/generations`）。
2. 模型名（例如 `seedream`、`flux`、`sd` 之类）。
3. 请求格式：JSON 还是 multipart；返回 URL 还是 base64。
4. 计费方式与并发限制。
5. 是否支持中文提示词、图片尺寸、负面提示词。

这些信息在服务商的文档或控制台里。没有确认之前，不要猜接口。

---

## 2. 密钥怎么放

### 本地开发

在项目根目录建 `.env.local`（已在 `.gitignore` 里）：

```
IMAGE_API_BASE=https://api.2ndcv.com
IMAGE_API_KEY=__填在这里__
IMAGE_MODEL=__模型名__
```

### 线上

在 Vercel 的 Environment Variables 里加同名变量。

### 代码

- 前端永远不读 `IMAGE_API_KEY`。
- 所有生图请求走 `/api/image` 这个服务端函数（Serverless Function，一段跑在服务器上的小函数）。
- 前端只传提示词和尺寸，不传 key。
- 服务端函数加：输入长度限制、超时 30 秒、每 IP 每分钟 5 次、返回错误码。

## 3. 最少要生成的素材

| 素材 | 数量 | 尺寸 | 备注 |
|---|---|---|---|
| 阿针立绘 | 6 | 1024×1024 | 6 个变体，统一风格 |
| 地标卡 | 6 | 1024×1024 | 老邮局、钟楼、河边面馆、旧书店、修表铺、老茶馆 |
| NPC 头像 | 8 | 512×512 | 圆形裁切 |
| 海报底纹 | 1 | 1080×1920 | 纸纹/铜版纹理，不含文字 |
| 地图纹理 | 1 | 1024×1024 | 可选 |

**风格提示词（中文）**：

> 复古黄铜 + 手绘铜版画 + 夜行手账；深墨蓝背景；暖黄侧光；细线交叉排线；低饱和；无文字；无 brand logo；不要赛博朋克；不要 3D 渲染。

**人物提示词（阿针）**：

> 一枚手掌大小的黄铜罗盘，拟人化，表盘上有一只半睁的眼睛，指针像眉毛，边缘有磕碰痕迹，复古铜版画风格，深墨蓝背景，暖黄侧光，手绘质感，无文字。

## 4. 先测一张

接入当天先用最低成本跑一张 512×512 的测试图，确认：

- 返回格式能解析。
- 图片能下载并转成 WebP。
- 失败时前端能回退到本地占位图。

测试通过再批量生成。批量生成时逐张保存到 `assets/source/`，记录提示词和种子，方便复现。
