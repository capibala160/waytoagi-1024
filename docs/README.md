# 问心·指南针 · 文档索引

> 一款"反向导航"城市冒险应用：你选目的地，罗盘只指方向，不给地图、不给路线。你靠自己的方向感、街上的线索和路人的指路抵达。抵达后自动生成旅程小结图和冒险日记。
>
> 当前主入口：**v2 高清界面**。根路径 `/` 自动跳 `/v2/`；旧根应用保留在 `/legacy.html`。
> 黑客松演示：真实出行（定位可信 + 罗盘 + 用户确认抵达）、雾城模拟、5/3 站寻宝都能玩。
> **PRD v0.2（R1-R11）是下一版需求；R10/R11（静态大罗盘）已提前落地，其余未实现**；逐项对照见 `STATUS.md` 的「v0.2 需求 vs 当前实现」。
> v0.2 需求目标：可玩的**旅程模拟**（60 秒左右第一次抵达）+ **游戏模式**（雾城挑战），评委在桌前 5 分钟能玩一局。
>
> **在线试玩：** https://capibala160.github.io/waytoagi-1024/

## 五个已定决策

1. **产品叫《问心·指南针》**，界面顶栏只写「问心」；主角仍叫阿针（"针"来自指南针）。"问心"是先想清楚要去哪，"指南针"是那件只指方向的工具。
2. **黑客松主入口是 v2**；真实出行先兑现「定位可信 → 指向可靠 → 用户确认抵达」，雾城模拟给室内/评委兜底。v0.2 再明确旅程 / 游戏两条顶层线。
3. **没有地图，抵达后才揭示路线。** 过程中只有罗盘、迷雾、街名和路人。
4. **问路是核心玩法，不是兜底。** 每个 NPC 只能问一次，有人会认真指错。
5. **日记和分享是产品的完成时刻。** 不是附加功能，是传播单位。
6. **到达由用户确认。** 系统只筛掉过期、低质量、漂移的定位；进入范围后由用户点「我到了」，不自动结算。

> **v0.2（2026-10-24）新增**：旅程 / 游戏分开；目的地详情卡（照片 + 理由）；首次模拟 60 秒；问路反馈；游戏两条计分线（速度 + 相遇）；日记从真实片段长出来；二维码分享；罗盘静态、只转指针、占据主视觉。详见 [PRD.md](PRD.md) 第 0 节。
