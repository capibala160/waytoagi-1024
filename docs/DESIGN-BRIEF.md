## 1. 视觉方向

**关键词：夜行手账 · 黄铜罗盘 · 铜版画 · 老地图 · 朱红印章**

不是赛博朋克，不是玻璃拟态，不是 SaaS 后台。是一本晚上带出门的旧旅行手账，里面夹着一枚被摸得发亮的铜罗盘。

### 1.1 参考物

- 老式航海罗盘：黄铜外圈、玻璃反光、刻度、红色指针。
- 铜版画/蚀刻版画：细线、交叉排线、单色。
- 中国老邮局：深绿木门、绿漆、黄铜把手。
- 旧地图：米色纸、折痕、铅笔标记。
- 朱红印章：抵达证明上的"已抵达"。

### 1.2 不要

- 不要紫色渐变、霓虹、玻璃卡片。
- 不要圆角 24px 的通用 App 卡片。
- 不要 emoji 当图标。
- 不要西式奇幻（龙、城堡、羊皮卷轴）。
- 不要大面积空白。信息密度要够。
- 不要把所有东西都做成同一种米色。

### 2.3 字体

| 角色 | 字体 | 字号 | 行高 |
|---|---|---|---|
| 品牌 / 大标题 | "Noto Serif SC", "Songti SC", serif | 32-40px | 1.2 |
| 屏幕标题 | 同上 | 24-28px | 1.25 |
| 区块标题 | 同上 / sans | 20px | 1.3 |
| 正文 / 行标题 | "Noto Sans SC", "PingFang SC", sans | 16-17px | 1.6 |
| 次级 | 同上 | 14px | 1.5 |
| 眉标 / 全大写 | 同上，letter-spacing 0.12em | 11-12px | 1.4 |
| 数字 / 计时 | "IBM Plex Mono", "SF Mono", monospace | 13px 最小；大数字 28-40px | 1.1 |
| 按钮 | sans，medium | 16-17px | 1.2 |

中文标题不要用黑体大粗字，用宋体/衬线，才有"旧手账"感。正文用黑体，保证可读。

### 2.4 间距与圆角

```css
--space-1: 4px;
--space-2: 8px;
--space-3: 12px;
--space-4: 16px;
--space-5: 24px;
--space-6: 32px;
--radius-card: 12px;
--radius-sheet: 20px 20px 0 0;
--radius-pill: 999px;
```

卡片圆角 12px，不要 24px。按钮用 10-12px 或胶囊，按场景。

### 2.5 质感

- 背景有一层很淡的纸纹（SVG noise 或 1 张 200KB 的纹理），透明度 3-5%。
- 黄铜元素用线性渐变 + 1px 高光，不要金属拟物到油腻。
- 卡片边框 1px `--line`，阴影克制。
- 印章用朱红 + 轻微旋转 + 边缘毛糙（CSS filter 或 SVG）。

### 4.2 游戏主界面

这是最重要的屏。HUD（游戏界面上的状态栏）要克制，罗盘和网格是主角。

```
┌─────────────────────────┐
│ 老邮局            ?  ⋯  │  ← 顶部 44px
│                         │
│        ╭───────╮        │
│        │  罗盘  │        │  ← 240px
│        │  ↑    │        │
│        ╰───────╯        │
│         "往那边。"       │
│                         │
│  ┌───────────────────┐  │
│  │  7×7 迷雾网格      │  │  ← 308×308
│  │  ·  ·  ·  ·  ·    │  │
│  │  ·  ▣  ·  ·  ·    │  │
│  │  ·  ·  ●  ·  ·    │  │
│  │  ·  ·  ·  ·  ·    │  │
│  └───────────────────┘  │
│                         │
│  ┌───┐  ┌───┐  ┌───┐   │
│  │ ← │  │ ↑ │  │ → │   │  ← 64px
│  └───┘  └───┘  └───┘   │
│        ┌───┐            │
│        │ ↓ │            │
│        └───┘            │
│                         │
│ 01:42   38 步   问路 3  │  ← 底部 56px
│ ─────── 日记 ────────   │  ← 把手
└─────────────────────────┘
```

- 罗盘 240px（390 屏）/ 260px（430 屏）。
- 网格视口 7×7，格子 44px（390 屏）/ 48px（430 屏）。**不要显示整张 12×12，太小。**
- 玩家始终在视口中心；走到边缘时地图平移。
- 迷雾未探索：`--surface` + 细网格线；已探索：`--paper` 10% + 路名；建筑：斜线填充；水：横向波纹；地标：图标 + 名字。
- 方向键十字布局，每个 64×64，间距 8px。
- 底部统计用等宽数字。
- 日记把手：宽 120px、高 4px 的横条 + "日记" 11px。

### 4.3 罗盘

- 外圈：黄铜渐变环，2px 高光。
- 刻度：60 条，每 30° 一条长刻度；正北有"北"字。
- 指针：朱红三角 + 尾部配重，中心黄铜帽。
- 玻璃反光：左上角一条 20% 白色斜光。
- 阿针的脸：表盘下半部，一只半睁的眼睛 + 一条眉毛（指针根部）。
- 靠近时：指针抖动 ±2°，外圈微微发亮。
- 抵达时：指针转 720° 后锁定在正上方？不，锁定在目的地方向，外圈闪一次。

### 4.4 问路对话卡

- 从底部升起，占屏幕 55%。
- 头像 72×72，圆形，铜版画风。
- 名字 20px 宋体，下面一行小字"这条路他熟"。
- 台词 17px，行高 1.7，最多 4 行。
- 底部按钮"记下了" 52px 高。
- 背景 `--surface-2`，顶部一条黄铜细线。

### 4.5 日记抽屉

- 半屏：占屏幕 60%，顶部圆角 20px，拖拽把手。
- 头部：目的地 + 日期 + 天气 + 旅伴。
- 数据行：4 个数据，等宽数字。
- 时间线：左侧竖线 + 节点；节点类型用不同图标（出发、问路、照片、抵达）。
- 照片位：3 个 96×96 的方框，虚线边框，中间 "+"。
- 底部：输入框 "记一句。不用长。" + 保存。
- 全屏：成稿区 + 语气切换 + 编辑。

### 4.6 结果页

- 顶部大字"到了。" 48px 宋体。
- 阿针的一句话 18px。
- 数据 4 列，数字 28px 等宽。
- 星级 3 颗，黄铜色，未点亮为线框。
- 标签两个胶囊："城市漫游者" "社交达人"。
- 按钮：主"写进日记"，次"再玩一局"，文字"挑战朋友"。
- 背景可以有一张很淡的路线图。

### 4.7 海报

- 1080×1920（设计稿里缩放到 270×480 展示）。
- 顶部：朱红"抵达证明"印章，旋转 -6°。
- 中间：目的地名 64px 宋体 + 日期。
- 路线：一条 6px 的黄铜线，画在纸纹上。
- 数据：2×2 网格，数字 40px 等宽。
- 阿针的话：引号 + 20px。
- 底部：品牌 + 链接。
- 整体像一张老车票/证书，不要像 Instagram 模板。

## 6. 动效

| 动作 | 时长 | 缓动 |
|---|---|---|
| 指针扫入 | 600ms | cubic-bezier(.2,.8,.2,1) |
| 指针跟随 | 240ms | ease-out |
| 迷雾揭开 | 200ms | ease-out |
| 移动一步 | 180ms | ease-in-out |
| 抽屉升起 | 320ms | spring |
| 抵达闪光 | 400ms | ease-out |
| 抵达锁定 | 1200ms | cubic-bezier(.1,.9,.2,1) |
| 页面切换 | 240ms | ease |

`prefers-reduced-motion` 时全部降到 0-100ms，去掉抖动和闪光。

## 7. 响应式

| 断点 | 宽度 | 调整 |
|---|---|---|
| 小屏 | 390×844 | 基准；罗盘 240；网格 44；边距 16 |
| 大屏 | 430×932 | 罗盘 260；网格 48；边距 20 |
| 桌面预览 | ≥ 900 | 手机框居中，背景留白；不改变内部布局 |

- 所有页面 `overflow-x: hidden`。
- 底部 `padding-bottom: env(safe-area-inset-bottom)`。
- 顶部 `padding-top: env(safe-area-inset-top)`。
- 文字 125% 缩放不裁切。

## 8. 可访问性

- 对比度：正文 ≥ 4.5:1，大字 ≥ 3:1。
- 点击区 ≥ 44×44，相邻 ≥ 8px。
- 按钮有 `aria-label`。
- 罗盘有文字替代："目的地在东北方"。
- 不只靠颜色：指针有形状，状态有文字。
- 焦点环可见：2px 黄铜色。
- 动效可关。

## 9. 设计稿文件结构

```
designs/
├── 01-onboarding.html     首页空、铸造、角色卡、模式、目的地、说明
├── 02-game.html           游戏、问路、日记抽屉、抵达、结果
├── 03-journal-share.html  日记全屏、海报、首页有内容
├── 04-real-settings.html  真实罗盘、设置、错误
└── assets/
    ├── azhen-north.webp
    ├── landmark-post-office.webp
    ├── npc-chess-uncle.webp
    ├── paper-texture.webp
    └── ...
```

每个 HTML：

- 顶部固定一个明暗开关，切换 `data-theme`，影响页面上所有手机。
- 每个手机是一个 390×844 的 `div.phone`，内部 `overflow: hidden`。
- 手机之间留 48px，背景 `--bg`。
- 页面标题用中文，左上角标注屏幕名和状态。
- 不引入外部 CSS 框架；字体用系统字体栈，Noto 作为可选。
- 图片先用 AI 生成的占位图；没有图就用 CSS 纹理 + 图标。

## 11. 验收

- [ ] 390×844 和 430×932 都不裁切、不横向滚动。
- [ ] 所有点击区 ≥ 44×44。
- [ ] 正文字号 ≥ 16px，最小可点文字 ≥ 13px。
- [ ] 深色和浅色都像"一本手账"，不是两个不同的 App。
- [ ] 罗盘是页面上最重的元素。
- [ ] 游戏屏在 3 秒内能看懂"我在哪、目的地在哪、怎么走"。
- [ ] 海报像证书，不像社交媒体模板。
- [ ] 没有 emoji 图标、没有紫色渐变、没有玻璃拟态。
- [ ] 每个手机框里都有真实中文文案。
