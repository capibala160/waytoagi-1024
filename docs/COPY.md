## 10. NPC

### 下棋大爷

> 老邮局啊。从这儿往东，过两个路口，看见钟楼再往北。我年轻的时候，那一片还是稻田。

### 外卖小哥

> 东三北二看到钟楼右转就是。

### 遛狗阿姨

> 邮局？往西走，过三个路口就到了。我天天走，错不了。

### 小学生

> 你先猜：什么东西越洗越脏？……水。答对了。往北两个路口，看到旧书店往东。

### 修表师傅

> 东。两个路口。北。一个路口。到了。

### 茶馆老板娘

> 老邮局啊？晓得晓得。你从这儿往东，走拢看到钟楼就拐。莫慌，慢慢走。

### 环卫工人

> 顺着这条街往东，走到头，过桥，再往北。慢点走，地上滑。

### 跑步的人

> 东边两个路口北转再东就到了我先走了。

### 不可靠 NPC 的错误版本

只改方向，不改人物语气：

> 遛狗阿姨：邮局？往东走，过三个路口就到了。我天天走，错不了。
> （实际应该往西）

> 下棋大爷：从这儿往南，过两个路口，看见钟楼再往北。
> （实际应该往东）

**原则**：错误必须能被另一个 NPC 纠正；不能让所有 NPC 同时错。

## 17. 错误与空状态

| 情况 | 文案 | 动作 |
|---|---|---|
| 定位被拒 | 没有定位，罗盘转不起来。去浏览器设置里打开定位，再试一次。 | 重试 |
| 方向被拒 | 手机不让我看方向。你可以看文字提示，或者打开系统指南针校准。 | 文字方向模式 |
| 信号弱 | 信号有点飘。走到开阔一点的地方。 | 继续等待 |
| 不支持 | 这个浏览器不支持罗盘。换 Safari 或 Chrome 试试。 | 复制链接 |
| 离线 | 网断了。罗盘还能用，日记先存在手机里。 | 继续 |
| 存储满 | 空间不多了。导出旧日记，再删掉几张照片。 | 去清理 |
| 分享失败 | 分享没成功。先保存图片，再发。 | 保存图片 |
| 链接失效 | 这个链接有点问题。回首页，重新走一局。 | 回首页 |
| 没有日记 | 还没有冒险。第一局，从楼下开始。 | 开始一局 |
| 没有照片 | 走到第一个路口，拍一张。 | 加一张 |
| 铸造失败 | 它有点认生。先用默认的阿针。 | 用默认 |

## 19. 文案禁忌

不要出现：

- "探索未知的自己"
- "遇见更好的自己"
- "城市灵魂"
- "治愈系"
- "宝子""家人们""绝绝子"
- "AI 赋能""智能体""大模型"
- 连续的感叹号
- 英文按钮（品牌名除外）
- "点击下方按钮"这类说明书语言

替换原则：

| 不要说 | 说 |
|---|---|
| 开启你的城市探索之旅 | 选一个目的地，走 |
| 智能推荐最适合你的路线 | 今天去老邮局 |
| 与好友分享你的精彩瞬间 | 把抵达证明发给他 |
| 记录美好生活 | 记一句。不用长。 |
| 迷路也别有一番风味 | 绕了就绕了。 |
