### 跑步的人

> 东边两个路口北转再东就到了我先走了。

### 不可靠 NPC 的错误版本

只改方向，不改人物语气：

> 遛狗阿姨：邮局？往东走，过三个路口就到了。我天天走，错不了。
> （实际应该往西）

> 下棋大爷：从这儿往南，过两个路口，看见钟楼再往北。
> （实际应该往东）

**原则**：错误必须能被另一个 NPC 纠正；不能让所有 NPC 同时错。

## 17. 错误与空状态

| 情况 | 文案 | 动作 |
|---|---|---|
| 定位被拒 | 没有定位，罗盘转不起来。去浏览器设置里打开定位，再试一次。 | 重试 |
| 方向被拒 | 手机不让我看方向。你可以看文字提示，或者打开系统指南针校准。 | 文字方向模式 |
| 信号弱 | 信号有点飘。走到开阔一点的地方。 | 继续等待 |
| 不支持 | 这个浏览器不支持罗盘。换 Safari 或 Chrome 试试。 | 复制链接 |
| 离线 | 网断了。罗盘还能用，日记先存在手机里。 | 继续 |
| 存储满 | 空间不多了。导出旧日记，再删掉几张照片。 | 去清理 |
| 照片满了 | 最多 9 张。先删一张，再加。 | 去删 |
| 搜索无结果 | 还没收录「XXX」。先试试：望平街 / 人民公园 / 九眼桥 | 选推荐 |
| 地点数据没加载 | 地点没加载出来。检查网络，再试一次。 | 重试 |
| 二维码生成失败 | 二维码没生成。先保存图片，或复制链接。 | 保存 / 复制 |
| 分享失败 | 分享没成功。先保存图片，再发。 | 保存图片 |

## 19. 文案禁忌

不要出现：

- "探索未知的自己"
- "遇见更好的自己"
- "城市灵魂"
- "治愈系"
- "宝子""家人们""绝绝子"
- "AI 赋能""智能体""大模型"
- 连续的感叹号
- 英文按钮（品牌名除外）
- "点击下方按钮"这类说明书语言

替换原则：

| 不要说 | 说 |
|---|---|
| 开启你的城市探索之旅 | 选一个目的地，走 |
| 智能推荐最适合你的路线 | 今天去老邮局 |
| 与好友分享你的精彩瞬间 | 把旅程小结图发给他 |
| 记录美好生活 | 记一句。不用长。 |
| 迷路也别有一番风味 | 绕了就绕了。 |

## 20. 视频旁白（短版）

> 导航软件告诉你每一步怎么走。
> 犟针只告诉你：往那边。
>
> 选一个目的地。罗盘只指方向，不给地图，不显示距离。
> 你得自己认路，或者问人。
> 路上的人会认真指路，也可能认真指错。
>
> 到了之后，它把你走过的路画成一张旅程小结图，再写一篇日记。
> 图上有二维码，朋友扫码就能走同一个地方。
> 主角叫阿针，一枚嘴硬心软的铜罗盘。
>
> 犟针。只指方向，不指路。
