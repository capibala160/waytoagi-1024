## 已知问题

- localtunnel 不稳定，会场 Wi-Fi 可能拦隧道；优先静态托管。
- 微信内置浏览器采样率 1 Hz；演示用自己的手机 + Chrome/Safari。
- 磁吸支架、音箱、金属桌会让罗盘偏；站远一点。
- 现有 App 是 5 关寻宝，不是目的地模式；对外口径要诚实。
- 现有 App 没有 GPS，所以旅程卡是“走完的站点”，不是真实轨迹。
- 现有 App 没有明暗切换；设计稿有，但今天不要为它改引擎。
- 名字冲突：《问津》是 App，《犟针》是文档。赛前不改代码名，赛后二选一。
- GitHub Pages 构建约 1 分钟；改完 `main` 等 1 分钟再看。
- 截图可能偏暗是淡入动画的第一帧；真机打开正常。
