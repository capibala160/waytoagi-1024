## 已知问题

- **真机 GPS / 磁罗盘还没实走**：定位逻辑通过模拟采样验证；实际户外精度、漂移和手机方向传感器仍需两款手机验收。
- **入口未实测**：六个目的地的 `entrance` 仍是「入口待实测」，中心点不一定能走到；现场逐个记录。
- **iOS iframe 方向权限**：罗盘校准页在 iframe 里申请方向可能被限制；失败时直接打开 `/compass-kit/demo.html`。
- **v2 没有根目录的全屏罗盘按钮**：游戏内用高清图层罗盘，校准页用 kit demo；旧根应用才有 iframe 全屏。
- **legacy 根应用不再维护**：`/legacy.html` 只做回滚，坐标/定位仍是旧逻辑，不要拿它验收。
- 微信内置浏览器采样率 1 Hz；演示用 Chrome/Safari/系统浏览器。
- 磁吸支架、音箱、金属桌会让罗盘偏；站远一点。
- localtunnel 不稳定，会场 Wi-Fi 可能拦隧道；优先静态托管。
- 名字现状：对外《问心·指南针》，界面顶栏「问心」（2026-10-25 定）。v2 与文档已统一；`game.js` / `classic/` / `smooth/` 属冻结备份，头注释仍写旧名「会场微定向」，按约定不改。
- GitHub Pages 构建约 1 分钟；改完 `main` 等 1 分钟再看；部署窗口内旧标签页可能缓存旧 JS。
- **当前模拟仍是雾城网格 + 方向键**；v0.2 R3 才改为「真的转手机 + 前进按钮（60 秒）」，代码未改。
- **当前顶层标签仍是「探索 / 游戏」**；v0.2 R8 计划改为「旅程 / 游戏」，代码未改。
- **v2 罗盘已改静态盘面**：底盘固定，只转指针指目的地；390 ≈343px、430 ≈353px，R10/R11 已提前落地。
- 会场寻宝在 v2 的「游戏」标签里，不是探索主入口；5/3 站均可玩。
- legacy 旧版没有 GPS；v2 真实出行已接 Geolocation（浏览器定位）和 DeviceOrientation（手机朝向），但真机复测仍是提交前必做。
- v2 已有明暗切换；旧根应用没有，别拿 legacy 验收主题。
- `smooth/` 是 2026-10-24 的冻结备份，不再维护；所有修改只进根目录。
