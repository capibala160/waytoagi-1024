### 1.1 我们主动加的两件事

1. **演练 + 实战双模式**：评委在桌前玩演练；视频里展示真实城市。既满足赛道，又不背叛产品愿景。
2. **抵达证明 + 挑战链接**：把"玩完"变成"可以发出去"，弥补赛道评分之外的产品价值。

### 2.4 成都落地

- **室内**：雾城按成都气质写。茶馆、竹椅、盖碗茶、掏耳朵、梧桐、锦水河、串串、麻将；不出现真实品牌名和真实小区名。
- **方言**：每个 NPC 最多一两个成都词（晓得、要得、走拢、莫慌、巴适），不做全篇方言，外地评委也要听懂。
- **室外视频**：用会场附近 3-6 个真实地点（宽窄巷子、人民公园、玉林、望平街，按距离选）。需要会场地址；拿不到就用成都街头空镜 + 室内演示，不阻塞提交。
- **评委感受**：让成都评委一眼认出"这是我们这儿"，但不要变成旅游宣传片。

### 2.1 作品说明（草稿）

> 《问心·指南针》是一款"反向导航"城市冒险游戏。你选一个目的地，罗盘只指方向，不给地图、不给路线、不显示距离。你要靠自己的方向感、街上的地标和路人的指路走到那里。NPC 会认真指路，也可能认真指错。抵达后，游戏把你走过的路画成一张"抵达证明"，并自动写成一篇冒险日记。主角阿针是一枚嘴硬心软的铜罗盘，只认一个方向，你绕路它会叹气。所有角色、地标和道具由 AI 生成，网页由 AI 编程工具完成。

### 2.2 演示视频脚本（3 分钟）

| 时间 | 画面 | 旁白 |
|---|---|---|
| 0:00-0:15 | 黑屏 → 问心 logo → 罗盘指针扫过 | "导航软件告诉你每一步怎么走。问心只告诉你：往那边。" |
| 0:15-0:35 | 《纽约客》标题 + 罗盘照片（可选） | "今年，一枚只指向一家餐厅的罗盘，让 5000 人排队。它卖的不是方向，是一段可以讲的故事。" |
| 0:35-0:55 | 一句话铸造 → 阿针出现 | "用一句话，造一个旅伴。它叫阿针，嘴硬，心软，只认一个方向。" |
| 0:55-1:10 | 选目的地：老邮局 | "今天去老邮局。没有地图。只有一个指针。" |
| 1:10-1:50 | 走、撞墙、迷雾揭开 | "城市只露出脚下一格。你得自己记路。" |
| 1:50-2:20 | 问下棋大爷 → 问遛狗阿姨（一个对一个错） | "你可以问路。有人指得对，有人指得特别自信，但完全是反的。" |
| 2:20-2:35 | 抵达，指针锁定 | "到了。阿针只说一句：'到了。我早说过。'" |
| 2:35-2:50 | 结果 + 日记 + 海报 | "用时、绕路、问了几个人，自动变成一篇日记和一张抵达证明。" |
| 2:50-3:00 | 真实城市罗盘（视频素材）→ logo | "明天，去真实的城市走一趟。问心，只指方向，不指路。" |

**录制要求**：

- 1080p，30fps，横屏或竖屏均可；竖屏更适合手机观看。
- 中文旁白，配中文字幕。
- 不要念参数，讲体验。
- 最后 5 秒留二维码/链接。

## 4. 砍清单

按顺序砍，砍到能交付为止。**核心四件永远不砍：罗盘、移动、抵达、重开。**

| 顺序 | 砍什么 | 砍了之后 |
|---|---|---|
| 1 | 实战模式 | 只保留演练模式；视频里用概念图代替 |
| 2 | 实时 LLM 铸造 | 用 6 个预设角色 + 关键词映射 |
| 3 | AI 日记成稿 | 用固定模板，仍可编辑 |
| 4 | 事件卡 / 道具 | 不做 |
| 5 | 分享海报 | 退化为文字分享 + 链接 |
| 6 | 冒险广场 | 首页只留"开始"和"我的冒险" |
| 7 | 音效 / 震动 | 静音 |
| 8 | 明暗切换 | 只做深色（但项目规则要求两套，尽量保） |
| 9 | 角色卡导出 | 用截图代替 |
| 10 | 动画细节 | 只保留抵达锁定 |

**不能砍**：

- 中文界面
- 44×44 点击区
- 抵达后的结果页
- "再玩一局"
- 一个能记住的主角
- 无空按钮

## 5. 试玩计划

### 5.1 对象

5 个没看过说明的人：2 个同事、2 个非技术朋友、1 个 50 岁以上的人（对应项目的"50+ 可读性"规则）。

### 5.2 观察

| 指标 | 记录方式 | 目标 |
|---|---|---|
| 首次移动时间 | 秒表 | < 30 秒 |
| 完成一局时间 | 秒表 | < 6 分钟 |
| 卡点 | 记录在哪一屏停住 | 0 个超过 10 秒的卡点 |
| 问路次数 | 游戏数据 | ≥ 1 |
| 想再玩 | 问"还想再来一局吗" | ≥ 60% |
| 描述阿针 | 问"主角是什么性格" | 100% 能说出"固执/嘴硬/只指方向"之一 |

### 5.3 修什么

只修前三个最大摩擦点。不要在第 13 个小时重做视觉。
