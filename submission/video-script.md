# 演示视频脚本 · 3 分钟

> 1080p / 30fps / 竖屏优先。中文旁白 + 中文字幕。
> **旁白即字幕**，下面每行按「秒数 | 画面 | 旁白」写。全片旁白约 460 字，正常语速 2 分 50 秒念完，留 10 秒收尾。
> 录屏用 390×844 手机视口；真实出门一段用手机实拍，没有就整段删掉，不补假镜头。

## 分镜

| 时间 | 画面 | 旁白（=字幕） |
|---|---|---|
| 0:00–0:08 | 黑屏。一行白字淡入：导航告诉你每一步。 | 导航软件会告诉你每一步怎么走。 |
| 0:08–0:16 | 罗盘从暗处亮起，指针扫过，锁定。标题《问心·指南针》 | 问心只告诉你一件事：往那边。 |
| 0:16–0:30 | 首页。手指输入「太古里」→ 结果 → 目的地卡 | 你说一个地方。它给你一张卡：这是什么地方，适不适合现在去。 |
| 0:30–0:42 | 点「去这里」→ 怎么走：雾城模拟 / 去真实城市 | 然后选怎么走。桌前用模拟，出门就去真实城市。 |
| 0:42–1:05 | 雾城模拟：指针转、走一格、撞墙停住、雾散开一格 | 模拟里你只看得到脚下一格。指针朝上就往前走，撞墙了就绕。 |
| 1:05–1:30 | 问路：点「问了个人」，NPC 弹出，一个指对、一个指反 | 走不动可以问路。有人指得对，有人指得特别自信，但完全是反的。 |
| 1:30–1:45 | 抵达：指针锁定 → 点「我到了」→ 结算页（用时 / 问路 / 星级） | 到了，按一下「我到了」。没有失败，走到就算数。 |
| 1:45–2:05 | 真实城市：手持手机转身，指针跟着转；走到街口，指针指向路口 | 出门的时候，指针跟着你转。它不会告诉你还有多远，只告诉你现在该朝哪边。 |

> **B 版旁白（手机没有罗盘时用这条，别硬念 A 版）**：
> 「出门的时候，指针只指着一个方向。它不会告诉你还有多远，只告诉你现在该朝哪边。」
> 画面配：手指拖动表盘对准街口 → 沿街走 → 抵达。**不要说「跟着你转」**，这句在没传感器的机器上是假的。
| 2:05–2:25 | 抵达结果 → 写日记（时间线 + 照片位 + 一句话）→ 生成旅程卡 | 抵达之后，这一趟会变成一篇日记和一张旅程卡。 |
| 2:25–2:40 | 主角卡：一句话铸造 → 三个阿针变体 → 保存 1080×1350 | 旅伴也是一句话造的。它叫阿针，嘴硬，心软，只认一个方向。 |
| 2:40–2:52 | 旅程卡上的挑战链接；切回首页 | 把链接发给朋友，让他走同一条路。然后，换一个地方再来一次。 |
| 2:52–3:00 | 结尾卡：产品名 + 链接 + 二维码 | 问心·指南针。只指方向，不指路。 |

## 录屏速查（页面自带走查参数，不改变产品逻辑）

| 要拍哪屏 | 地址 |
|---|---|
| 首页 | `https://capibala160.github.io/waytoagi-1024/v2/` |
| 行进 / 罗盘 | `…/v2/?preview=play&still=1` |
| 抵达结果 | `…/v2/?preview=end&still=1` |
| 日记 | `…/v2/?preview=diary&still=1` |

**坑（2026-10-25 实测）**：从 `?preview=end` 直接点「写日记」会提示「还没有可写的一局」——因为走查参数只填了结算数字，没填日记数据。拍日记用 `?preview=diary`；真玩一局走到底再点「写日记」也是正常的。`?preview=diary` 下点「生成日记」已实测能出正文（99 字，含《太古里》和时间线）。

`still=1` 关掉淡入动画，否则录到的第一帧是透明的。
